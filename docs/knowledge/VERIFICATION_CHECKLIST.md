# Checklist verifikasi pengetahuan

Isi per entri, sertakan bukti dan pemeriksa. Kotak di bawah belum dicentang karena belum ada pemeriksaan PDF/data domain.

- [ ] PDF sumber diperoleh, dibaca, dan versi/tautan dicatat.
- [ ] Kelas hama dipisahkan dari penyakit/kekurangan nutrisi; setiap nama dan deskripsi punya locator sumber.
- [ ] Setiap gejala memiliki definisi/label dan locator sumber yang jelas.
- [ ] Setiap aturan hama–gejala memiliki asal `cf_expert` dan locator tepat; skala serta maknanya sesuai metode.
- [ ] Premis AND/OR pada sumber diperiksa dan tidak diubah menjadi aturan tunggal tanpa kajian.
- [ ] Penanganan, jika ditampilkan, diperiksa per hama dan sumbernya dicatat.
- [ ] ID/referensi/bobot/duplikat divalidasi oleh loader; mode verified menolak data demo.
- [ ] Pemeriksa, tanggal, keputusan, dan bukti dicatat untuk tiap perubahan status ke `verified`.
- [ ] Kasus evaluasi memiliki label pakar dan terpisah dari penetapan/penyetelan bobot.

Format catatan entri: `ID entri | jenis | sumber | locator | kutipan/parafrasa singkat | keputusan | pemeriksa | tanggal`. Jangan masukkan data nyata hanya berdasarkan asumsi atau contoh sintetis.
